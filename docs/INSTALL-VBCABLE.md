# VB-Cable installation

This project does not redistribute the VB-Cable driver installer. Download and install the matching VB-Cable package from the official VB-Audio website, then restart Windows audio or reboot Windows.

After installation, route the applications you want to cast to `CABLE Input` in the Windows volume mixer. HomePodTray reads from the virtual cable or the selected process; it does not change the system default output or mute other applications.

The endpoint names are usually `CABLE Input` and `CABLE Output`; use the names shown by your system.
