# HomePodTray v0.1.0 — Windows x64 实验性预发布

这是首个预发布的说明草稿，**目前尚未发布，也没有附件下载**。正式创建时应标记为 Pre-release，并在发布前更新安装与首次播放的验收状态。

HomePodTray 是带中文窗口和托盘菜单的 Windows 工具，用于将勾选应用的音频通过局域网 AirPlay 投射到 HomePod。可使用 QQ 音乐或其他播放器；它与 Apple、HomePod、QQ 音乐和 VB-Audio 没有官方关联。

## 本版功能

- 默认仅捕获勾选的应用，未勾选时等待，不自动投射全部系统声音。
- 可选“仅 HomePod”“HomePod + 电脑默认输出”“仅电脑默认输出”。所选播放器须事先路由到虚拟声卡。
- HomePod 音量 0–100 实时调整；手动连接/断开、重置音频链路、托盘驻留和可选开机启动。
- 支持虚拟声卡端点诊断采集；该模式下应用勾选名单不生效。
- 不修改系统默认音频设备、其他应用路由、EQ、响度均衡或驱动采样率。

## 使用条件

主要目标为 Windows 11 x64。按应用采集 API 要求 Windows build 20348 及以上；普通 Windows 10 22H2 build 19045 不支持该模式。端点诊断模式不构成完整 Windows 10 兼容承诺。

需要已用 iPhone/iPad 初始化的 HomePod、同一局域网和单独安装的 VB-Cable。主要面向无需 PIN 的 HomePod 临时配对；完整 PIN/密码配对界面尚未实现。

安装包未做数字签名，Windows 可能显示未知发布者提示。

## 拟发布包的安装步骤

1. 解压完整 ZIP，运行 `01-HomePodTray-Setup.exe`，安装到当前用户目录。
2. 安装器可选请求管理员权限添加仅针对 HomePodTray、远端为 `LocalSubnet` 的入站 UDP 规则。拒绝授权仍可安装；首次连接失败时需手动检查放行，不要关闭防火墙。
3. 打开包内 VB-Cable 官方链接，下载并完整解压驱动包，以管理员身份运行 x64 安装程序，然后重启电脑。
4. 将 QQ 音乐或其他播放器的输出路由到 `CABLE Input`，其他应用保留原输出。
5. 确认电脑与已初始化的 HomePod 在同一局域网，打开 HomePodTray，选择 HomePod、虚拟声卡和投射应用。
6. 选择播放目标，点击“应用设置”和“连接”，开始播放。手机/iPad 接管前先断开电脑投射。

安装器不安装 VB-Cable，也不自动连接或播放。卸载保留用户配置、日志及 VB-Cable；删除安装器的防火墙规则需管理员授权，拒绝时需手动清理。

## 已知限制

本地和 HomePod 输出尚未对齐延迟；完整 PIN/密码配对、IPv6/跨网段发现、任意多物理输出、自动更新尚未实现。

音频最终输出为 44100 Hz / 16-bit / 双声道，通过上游 AirPlay 2 实时 RAOP 与加密 ALAC 传输；播放器的更高采样率或位深不会原样透传。日志可能含接收器地址，反馈问题前请检查敏感内容。
