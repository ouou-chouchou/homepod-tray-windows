# HomePodTray 0.1.0 快速开始

适用 Windows 11 x64。按应用采集要求 Windows build 20348 及以上，普通 Windows 10 22H2 不支持。它是第三方实验性工具，与 Apple、QQ 音乐、VB-Audio 没有官方关联。

1. 解压完整 ZIP，运行 `01-HomePodTray-Setup.exe`。软件安装到当前用户目录，创建桌面/开始菜单快捷方式和卸载入口。
2. 安装时可选添加 UDP 防火墙规则，会请求管理员权限。规则只允许本地子网向 HomePodTray 发送 UDP；拒绝仍可完成安装。
3. 打开 `02-请从官方渠道下载 VB-Cable.url`，从 https://vb-audio.com/Cable/ 下载完整官方压缩包，全部解压后，以管理员身份运行 x64 驱动安装程序，再重启电脑。不要只复制 Setup.exe。
4. 用 iPhone/iPad 初始化 HomePod，确保它和电脑处于同一个局域网。
5. 在 Windows 音量混合器把 QQ 音乐或其他播放器的输出设为 `CABLE Input`，其他应用保持原输出设备。
6. 打开 HomePodTray，搜索或填写 HomePod 地址，选择虚拟声卡、勾选播放器，选择“仅 HomePod”。
7. 点击“应用设置”和“连接”，再播放音乐。

HomePod 音量可以在窗口实时调节。关闭窗口隐藏到托盘；退出请使用托盘菜单。手机/iPad 接管前先断开电脑投射。

如果没有声音，检查播放器是否已经路由到 CABLE、是否勾选正确进程、HomePod 是否在同一局域网并允许访问。如果配对成功但连接超时，检查安装路径对应的 UDP 入站防火墙规则。不要关闭系统防火墙。

卸载 HomePodTray 可在 Windows“已安装的应用”中进行；卸载保留配置、日志及 VB-Cable。删除防火墙规则需要管理员权限；拒绝授权时请手动删除 `HomePodTray - HomePod UDP in` 规则。

本程序不修改默认音频设备、其他应用路由、EQ 或驱动采样率。软件未做数字签名，Windows 可能显示未知发布者。长期稳定性和不同网络、设备兼容性仍需测试。
